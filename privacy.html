Privacy Policy

Gmail & Contacts MCP Connector — last updated 2026-10-05

1. Scope

This policy describes how the Gmail & Contacts MCP Connector ("the Application") handles information obtained from Google APIs. The Application is a private, single-user tool operated by, and for, one individual — the owner of the Google account it is authorized against.

2. Information the Application accesses

Google API scopePurpose
https://mail.google.com/ Read, search, label, compose, send and delete the owner's own Gmail messages.
https://www.googleapis.com/auth/contacts Read, create, update and delete the owner's own Google Contacts.
https://www.googleapis.com/auth/contacts.other.readonly Read the owner's "Other contacts" list.

No other Google data is requested or accessed. The Application does not access Google Drive, Calendar, Photos, location data, or any other Google service.

3. How information is used

Accessed data is used solely to perform the operations the owner explicitly requests through a local AI assistant running on the owner's own computer. There is no automated profiling, advertising, or analytics of any kind.

4. Where information is stored

  • No server. The Application has no backend, no database, and no cloud storage. It communicates directly from the owner's computer to Google's APIs over HTTPS.
  • OAuth credentials (access token, refresh token, client credentials) are stored in a local file on the owner's own machine.
  • Message and contact content is processed in memory and is not written to any persistent store by the Application, other than transient local caches created by the operating system or the assistant's local runtime.

5. Disclosure to third parties

None. No data is sold, rented, traded, shared, or transmitted to any third party. No third-party analytics, telemetry, crash reporting, or advertising SDKs are used. No data is used to train machine-learning models.

6. Data retention and deletion

  • Data is retained only for as long as it exists in the owner's own Google account.
  • The owner may delete the locally stored OAuth credentials at any time by deleting the credential file on their machine. This immediately and permanently revokes the Application's local access.
  • Access may also be revoked at any time from the Google Account permissions page: myaccount.google.com/permissions.

7. Security

All communication with Google APIs uses HTTPS/TLS. OAuth credentials are stored only on the owner's own device, under the operating system's user-profile permissions. The Application does not transmit credentials anywhere.

8. Children's privacy

The Application is not directed at children and is not available to the public.

9. Changes to this policy

Any changes will be published on this page with an updated "last updated" date.
